# Kit "Copie, pegue, venda": 8 prompts para su negocio

Landing móvil de Bresco Media para captar leads por WhatsApp con el Kit de prompts gratuito.

- `index.html`: página completa (HTML, CSS y JS en un solo archivo, sin dependencias salvo Google Fonts).
- Para cambiar el número de WhatsApp, edite la variable `N` al final de `index.html`.
